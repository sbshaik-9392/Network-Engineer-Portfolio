# OSPF End-to-End Connectivity Verification

## Objective
Verify end-to-end connectivity between all three LANs using OSPF single-area routing.

## IP Addressing

| Device | IP Address | Default Gateway |
|---|---|---|
| VPCS01 | 192.168.1.10/24 | 192.168.1.1 |
| VPCS02 | 192.168.2.10/24 | 192.168.2.1 |
| VPCS03 | 192.168.3.10/24 | 192.168.3.1 |

- All six directed ping tests shown in the screenshots succeeded.
